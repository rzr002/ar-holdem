# AR Hold’em 本地试玩

这是 Lens Studio 中的 SPECS 桌面仿真体验，不是实体眼镜实测。六人桌包含你（YOU）和五名电脑对手，使用虚拟筹码。默认 Lucas v16 在本地运行，不需要登录 Codex，也不需要 API key；它是基于牌力评估、规则和对手行为统计的程序策略，不是 LLM 或训练模型。

## 启动

全新检出工程的 Python 环境、依赖安装、可选 Codex/API 配置和 Lens Studio 打开步骤见 [RUNNING.md](lens-studio/ARHoldem/devpost/RUNNING.md)。已有环境可在仓库根目录运行：

```bash
./ar/run.sh
```

打开 `ar/lens-studio/ARHoldem/SpecsBaseTemplate.esproj`，在 SPECS Interactive Preview 查看牌桌。点右下角 `Deal` 发牌，再用鼠标点击按钮；若轻点未触发，可按住约 0.2 秒再松开。`THINKING` 表示电脑正在决策，结算后点 `Next hand`。

常用操作：`Fold` 弃牌；`Check` 过牌；`Call` 跟注；`Raise to` 加注至显示的总额；`Pot to` 按底池预设加注；`All-in` 全下。决策失败时，牌局暂停并提供 Retry；不会自动切换对手类型。

## 可选对手模式

- 默认 `./ar/run.sh`：本地 Lucas v16。
- Codex：`./ar/run.sh --mode codex`，默认请求 `gpt-6-luna`；需要已配置好的 Codex CLI。
- OpenAI-compatible API：`./ar/run.sh --mode api`，需要用户自行配置兼容服务、模型名和密钥环境变量。
- 测试：`./ar/run.sh --mode strategic` 或 `--mode local`，Lens 会标注 `OFFLINE TEST`。
